## Visão geral
Esse projeto tem como objetivo criar um sistema de trade  chamado SentinelTrade. O sistema é projetado como uma plataforma distribuída, segura, escalável e tolerante a falhas. Ele permite que os investidores acompanhem cotações de mercado, mantenham uma carteira de ativos, enviem ordens de compra e venda e consultem o histórico de operações.
O sistema garante alta confiabilidade através de autenticação multifator (MFA), validações rigorosas de saldo e risco antes do envio de ordens, prevenção de duplicidade e geração de logs de auditoria imutáveis.

## Estrutura do repositório
O repositório está organizado para separar a documentação do código-fonte. Ele está estruturado da seguinte maneira:
- docs/ - Contém a especificação dos requisitos funcionais e não-funcionais, o contexto do projeto e diagramas UML (como o Diagrama de Casos de Uso).
- src/ - Código-fonte do projeto
- .env.example - Template com as variáveis de ambiente necessárias para a configuração do sistema.
- .gitignore - Ignora arquivos específicos do projeto
