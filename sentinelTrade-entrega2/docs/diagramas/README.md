# Diagramas — SentinelTrade

Todos os diagramas do projeto ficam nesta pasta. Clique em **Ver PNG** para ver a imagem.

Cada diagrama tem dois arquivos:

- **`.png`** — a imagem, que o GitHub mostra direto na tela. Fica nesta pasta.
- **`.drawio`** — o arquivo editável do [draw.io](https://app.diagrams.net) (é um XML). Fica na subpasta [`editaveis/`](./editaveis).
