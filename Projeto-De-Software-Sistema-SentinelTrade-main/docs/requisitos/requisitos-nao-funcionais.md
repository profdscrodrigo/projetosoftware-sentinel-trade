# Requisitos Não Funcionais

Os requisitos não funcionais representam características de qualidade e restrições da solução.

| ID | Categoria | Descrição |
|---|---|---|
| RNF-01 | Segurança | O sistema deve proteger os dados contra acessos não autorizados. |
| RNF-02 | Comunicação | As comunicações entre os componentes devem ser protegidas. |
| RNF-03 | Disponibilidade | O sistema deve possuir mecanismos para lidar com indisponibilidade de componentes. |
| RNF-04 | Escalabilidade | O sistema deve permitir expansão para suportar o crescimento de usuários e operações. |
| RNF-05 | Tolerância a Falhas | O sistema deve possuir mecanismos para lidar com falhas de componentes. |
| RNF-06 | Recuperação | O sistema deve possuir mecanismos de recuperação após falhas. |
| RNF-07 | Integridade | O sistema deve preservar a consistência dos dados de contas, carteiras e ordens. |
| RNF-08 | Rastreabilidade | As operações relevantes devem poder ser rastreadas. |
| RNF-09 | Auditoria | Os registros de auditoria devem ser protegidos contra alterações indevidas. |
| RNF-10 | Confiabilidade | O sistema deve evitar duplicidades e inconsistências durante o processamento das ordens. |
| RNF-11 | Distribuição | A solução deve ser organizada como uma plataforma distribuída, permitindo a comunicação entre seus componentes. |
